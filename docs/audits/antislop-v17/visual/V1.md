# V1 — The home (classic, cover, profile tabs, the 7 stats sections), the header, the search modal
Summary: The home is the strongest screen when you look at its top-left: game art, real titles, the display-italic
name and RA's own "rich presence" line are things no other site has. Everything under and around that reads like
a generic analytics dashboard: an admin-style side rail of 7 icon tabs, a 6–7 figure KPI row in 10 px uppercase,
a heatmap and a line chart that repeat each other, and cards inside cards inside cards. The same facts are shown
two or three times (last played game, pinned games, "this week"), and some disagree with each other on screen.
The 3 things that most make it feel vibecoded: **(1) the uppercase tracked kicker on every block, next to two other
label styles**; **(2) three hand-made tab bars on one screen, each with its own shape** (straight underline, slanted
underline, raised pill), which is also where "slanted feels inconsistent" comes from; **(3) breadth over focus**:
7 sections, of which 3 are copies of pages already in the header (Grupos, Siguiendo, Explorar).

**Capture caveat (read first, tell the coordinator):** the signed-in shots are **not** a valid slanted/round pair and
the **cover layout was never captured**. `shape-style` and `home-layout` are synced preferences ("the account wins",
`usePreferencesSync`), so the account's own values overwrote what `capture.js` put in localStorage. Evidence:
`app/home-classic__round__dark__2560.jpg` and `app/home-cover__slanted__dark__2560.jpg` are byte-identical;
`home-cover__{slanted,round}__390` equal `home-classic__slanted__390`; 7 more round/slanted pairs are byte-identical
(groups, browse, collection 2560, pinned-tab 390, profile-xbox 390, search 2560); and every "round" shot shows the
KPI row's slanted rules, which are `skew-x-(--slant-button)` = `0deg` in the round design. The theme is also the
account's (white accent), not `dark` (violet `#a78bfa`). So all app/ and modals/search shots are **slanted**; my
slanted-vs-round notes below come from the tokens and code. To capture round and cover: set them through
`PUT /api/preferences` (or the Layout modal) for the test account, not localStorage.

### V1-01 · HIGH · bug
- **See:** `app/home-classic__slanted__dark__2560.jpg`, profile card, "Ratio hardcore 285 %" (crop `v1-prof-round.jpg`).
- **What:** "Ratio hardcore" is computed as `TotalTruePoints / TotalPoints × 100` — that is RetroAchievements' RetroRatio
  (true points over points, a difficulty weight: 26 033 / 9 121 = 2.85), not a share of the account played in hardcore.
  A "ratio" over 100 % is visibly wrong to any RA player. The avatar ring is coloured from the same number
  (`≥ 80 → hardcore gold`), so it is gold for practically every account.
- **Why it matters:** a wrong figure on the most-seen card undoes trust in every other figure.
- **Code:** `src/components/main-page/main-page-profile/main-page-profile-ra/MainPageProfileRa.tsx:38-44`, label `T.profileStats.hardcoreRatio`.
- **Proposal:** either show RA's own term ("RetroRatio 2,85", unitless, `decimal(n, lang)`) or compute the hardcore share as
  `hardcore / (hardcore + softcore)` (here 83 %) and keep the ring on that. Owner picks which fact they meant.

### V1-12 · MED · bug (UX)
- **See:** `modals/search__slanted__dark__2560.jpg`, `…__390.jpg`: the box holds "/" and says "0 resultados — No se encontraron
  juegos en tu librería".
- **What:** the header's search bar starts with a slanted accent tick that looks exactly like a "/" keyboard hint (the web convention:
  GitHub, YouTube). Pressing "/" opens search **with "/" typed in it**, so the first thing a keyboard user sees is "no games found".
  Any printable key opens search with that key as the query (type-to-search), "/" included.
- **Code:** `src/components/main-header/MainHeader.tsx:89-99` (`setInitialQuery(e.key)`), tick at `:190`.
- **Proposal:** treat "/" as "open empty" (`initialQuery = e.key === '/' ? '' : e.key`). The tick can stay as the brand mark; or
  show a real `/` kbd hint at the right, which makes the convention explicit.

## Cross-cutting patterns seen
- **Same fact, several places** (last played game ×2, pinned games ×2, week ×3, level/streak ×2–3, whole pages repeated as sections).
  Cutting duplicates is the biggest simplicity win and needs no new design (V1-03, V1-04).
- **Three label systems** (uppercase kicker, sentence-case tile label, bold heading) and **four figure styles** on one screen (V1-06, V1-10).
- **Hand-made siblings of library pieces** (three tab bars, two add tiles, tooltip, chips): the inconsistency the owner feels is mostly
  these drifts, not the slant itself (V1-05, V1-20; A-08, A-13, C-09).
- **Scope ambiguity**: blocks that silently count one platform next to blocks that count all (V1-02, V1-21).
- **Wrong or unlabelled numbers** (RetroRatio as "Ratio hardcore", points without a unit) cost more trust than any visual issue (V1-01, V1-09).
