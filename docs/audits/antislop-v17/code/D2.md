# D2 — Shared game components, library, status lists, collapsible section, day modal
Auditor notes: the library pieces (`library-*`) are mostly small, clean and well commented, so the folder count is not the
problem. Five things are. The four status cards are four copies of one shell. Older RA pieces (`AchievementModal`,
`GameHashesModal`, `AchievementGrid`, `GameInfoAchievementCard`, `AllGamesSection`) predate the library and still draw by
hand what `ui/` now has, with hard-coded English or Spanish. Every modal wraps `Modal` in a second portal and redraws its
head. The same small snippets are pasted everywhere: RA image URLs, the "bar + % that turns green" line, the achievement-type
tags. And "detail" names five different things.
On granularity: very few folders are over-split. CLAUDE.md asks for extraction ("when in doubt, extract"), so the fix is to
**nest** the single-use pieces under their parent and give them clear names, not to merge them back.
