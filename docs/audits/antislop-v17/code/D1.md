# D1 — Per-platform components (`psn/`, `steam/`, `xbox/`, `ra-*`, `steam-*`, `xbox-logo`, `user-game-page`)
Auditor notes: The code is careful one file at a time (accessible, tested, error-handled), but the area is mostly the same
eight components written three or four times, once per platform. Each copy was made by duplicating a sibling and renaming
fields, and the docblocks say so ("styled like X", "counterpart of Y"). About 4,500 of the area's 6,631 lines belong to
families of copies. One shared version per family, fed by a small adapter per platform, would bring that to roughly
2,000 lines (about −2,500). Second theme: things that are now shared still carry a platform name (`SteamPinAchievementButton`,
`SteamSortableHeader`, `RARecentlyPlayed`, Steam's anchor helper living in a component file). Third: small hand-drawn
controls (retry pill, notices, submit button) where `ui/` already has `Button` and `Notice`.

## Findings

### D1-01 · HIGH · duplication — the achievement table, its row and its phone card are written three times
- **Where:** `psn/psn-game-info-table/PsnGameInfoTable.tsx` (282), `xbox/xbox-game-info-table/XboxGameInfoTable.tsx` (263), `steam/steam-game-info-table/SteamGameInfoTable.tsx` (262); rows `PsnGameInfoTrophy.tsx` (114), `XboxGameInfoAchievement.tsx` (114), `SteamGameInfoAchievement.tsx` (99); cards `PsnGameInfoTrophyCard.tsx` (113), `XboxGameInfoAchievementCard.tsx` (111), `SteamGameInfoAchievementCard.tsx` (94); reveal eyes `PsnRevealTrophyButton.tsx` / `XboxRevealAchievementButton.tsx` (36 + 36, the only differences are two T keys and the ring colour). RA's `game-info-table/GameInfoTable.tsx` (outside the area) shares the shape but not the code.
- **What:** These are the same in all three files: the sort function (`sortTrophies`/`sortAchievements`: the rarity null rule, the "earned desc keeps locked last" rule, written 3×), the deep-link block (`useLocationHash` → `useWhenChanged` resets → `useEffect` scroll + 2.5 s highlight, 3×), the filter → search-by-shown-label → pinned-first `useMemo`, `handleSort`, fold/`ShowRestButton`, the `<table>` head with three `SteamSortableHeader`s, the desktop/phone split, and the `AchievementDetailModal` with its showcase object. In the row and the card, the icon cell, the stretched-button title, "Locked" in sr-only text, the pin cell and the highlight/pinned backgrounds match class for class.
- **What actually differs (the adapter):** id type (`number` PSN, `string` Xbox/Steam); anchor prefix (`#trophy-`, `#achievement-`, `#ach-` with `decodeURIComponent`) and data attribute (`data-trophy`/`-achievement`/`-ach`); field names (`name|title`, `detail|description`, `earnedAt|unlockedAt|dateEarned`, `rarity|globalPct`, `hidden|secret`, `earned|unlocked`, `iconUrl|badgeUrl`); default order (`id`, the order Xbox sent, `displayOrder`); one extra column (PSN grade, Xbox gamerscore, none on Steam); reveal (PSN and Xbox yes, Steam no); PSN's DLC `PsnTrophyGroupTabs`; Steam's "online" filter and `MissableNotice`; `guideLinks` source and title (`titleEn ?? title`, `appId`); the modal's `tags`; label keys.
- **Fix:** One `achievement-table/AchievementTable.tsx` (plus `-row`, `-card`) that takes a normalized row: `{ id: string; anchor: string; title; description; iconUrl; earned; earnedAt; rarity; secret; order; extra?: ReactNode; group?: string; online?: boolean }`. Each platform keeps a ~30-line adapter (`psnTableRows(trophies)`, etc.) and passes `extraColumn`, `notice`, `groupTabs`, `canReveal`, `guides(row)`, `showcase(row)`. Two normalized shapes already exist in `utils/` (`InsightAchievement` in `gameInsights.ts`, `CompareAchievement` in `gameCompare.ts`, which already has `grade`, `gamerscore` and `anchor`). Extending `CompareAchievement` avoids a third shape. Merge the two reveal buttons into one `RevealSecretButton` with labels passed in, and the two reveal hooks with them (`useRevealedTrophies` / `useRevealedAchievements` differ only in id type and the preference hook; they are outside the area).
- **Size:** 1,554 → ~600 (shared ~420, adapters ~3×40, plus PSN's group tabs).
